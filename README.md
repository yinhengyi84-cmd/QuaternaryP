# 极北铁幕 网页地图

首版包含 190 个真实行政地块与 172 条地理志记录，支持电脑、手机浏览器。React + TypeScript + Vite 构建，SVG + D3 绘制真实地图；无须在线地图账号或地图密钥。

## 启动

在此目录双击 `启动地图.cmd`，然后在浏览器打开屏幕显示的电脑地址，通常是 `http://localhost:5173/`。项目已附带构建好的网页，普通使用无需重新安装依赖或联网。

手机与电脑连接同一 Wi-Fi 后，打开启动窗口中的手机地址。保持启动窗口打开；按 Ctrl+C 停止服务。需要 Node.js 22.12 或更高版本，推荐 Node.js 24 LTS。

也可以在此目录打开终端执行：

```text
npm start
```

若手机无法连接，检查电脑与手机是否同一局域网，以及电脑防火墙是否允许该本地服务。请使用启动窗口中的实际地址，不使用手机自身的 localhost。开发修改时先运行 `npm ci`，再运行 `npm run dev`。

## 操作

- 鼠标拖动平移，滚轮缩放；手机使用单指拖动、双指缩放。
- 点击行省查看归属、中文名、现实原型、地理和剧情资料。
- 五角星表示六方首都，圆点表示战略城市；点击城市符号可打开其所属地块档案。地图拥挤时部分名称会暂时隐藏，放大后出现，城市符号始终保留。
- 搜索支持中文名、欧洲名称及原表编号，如 `长沙`、`Riga`、`D010`。结果可使用上下方向键和 Enter 选择，Ctrl+K 聚焦搜索。
- 左侧书本按钮打开全部地理志；六阵营图例可聚焦单一阵营，“全部”恢复显示。
- 十字准星按钮恢复全图。手机资料面板可通过右上角关闭按钮收起。

## 边界与资料

真实边界优先，地区数量与 Maps.png 的原始分块不完全相同。柏林、勃兰登堡、莫斯科市与莫斯科州等单独绘制；挪威的固定来源采用 2022 年合并郡。

`边界对应说明.md` 列出全部原表条目对应的真实地块。部分旧县与现代市镇的关联为暂定，页面会注明“对应待核”或“所属地区资料”。地图中的阵营为架空设定。

12 个城市标记存放在 `public/data/cities.json`，位置使用现实欧洲城市坐标。明斯克州在网页中显示为「合肥·明斯克州」，来源 Word 的 S047 原文仍保留供核对。

`public/data/atlas.json` 保存文字、初始阵营及对应关系，`geometry.geojson` 保存真实地块，`water.geojson` 保存真实湖泊。所有数据随项目提供，地图浏览无需访问第三方服务。`boundary-manifest.json` 保存下载版本、出处、许可证及文件校验值。数据来源条款见 `DATA_LICENSES.md`。

## 检查与构建

```text
npm run check:data
npm test
npm run test:e2e
npm run build
npm run preview
```

浏览器测试默认使用本机 Microsoft Edge。构建结果位于 `dist`，可部署到普通静态服务器；首版未提供互联网部署、房间、归属修改、登录或数据库。

## 后续扩展

地块稳定 ID、初始阵营与地理志记录已分开。后续可增加独立的对局状态，通过 Node.js 接口与 WebSocket 同步当前归属，不必改写静态边界。当前浏览版不记录玩家操作。

当前地图没有可调用的领土变更 API；建议的接口、版本号和同步事件格式见 `领土变更接口预案.md`。

维护边界数据时，`scripts/download_boundaries.py` 与 `download_water.py` 下载原数据到 `.cache/boundaries`；保留元数据文件即可复用同一固定下载版本。`scripts/build_atlas.py` 校验原 Word 内容并生成网页数据。普通运行与构建不需要 Python或重新下载边界。
